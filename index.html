AiO Debian GUI

Mantenimiento, diagnóstico y programación de tareas para Debian y Ubuntu LTS, con interfaz gráfica GTK.

Instalación y actualización

Elige DEB para integrarlo con APT, AppImage para ejecutarlo como archivo portable o Flatpak desde el repositorio firmado del proyecto.

  • Última release estable: DEB, AppImage, Flatpak y SHA256SUMS
  • Instrucciones de instalación y actualización por formato
  • Instalar Flatpak desde el origen firmado
  • Guía de actualización de Flatpak y migración desde bundle

El DEB configura el repositorio APT. AppImage descarga las nuevas versiones desde GitHub; Flatpak se actualiza desde su origen propio. La integración de programación para los formatos portables utiliza el paquete firmado aio-debian-gui-host, sin requerir la interfaz DEB.
